# Duck
An rp2040 devboard that can be coded up to play a loud noise when pressed with a keyboard switch. The original goal for the project was to make it play a loud noise of your choice when you press the switch, but i wanted to make it more customizable so now its a pcb that you can do whatever with. sadly i did privitize my lapse links cause i put some pii in them so you will just have to trust my :hs:
